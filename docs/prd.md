# 个人资产管理平台 PRD

- **产品名称**：个人资产管理平台（暂定名：`NetWorth`）
- **文档版本**：V1.0
- **文档日期**：2026-05-20
- **适用端**：Web / iOS / Android
- **产品定位**：面向个人用户的资产、负债、现金流、投资与目标管理工具，帮助用户“看清净资产、管好现金流、追踪财务目标”。

---

## 1. 背景与问题定义

### 1.1 现状痛点

个人用户在管理财务时通常面临以下问题：

1. **资产分散**
  - 银行卡、现金、基金、股票、房产、贷款、信用卡等信息分散在不同平台。
  - 无法快速知道自己“到底有多少钱”。
2. **记账与资产视角割裂**
  - 记账类产品偏重收支流水，无法直接反映净资产变化。
  - 投资类工具偏重收益率，无法统一管理所有资产负债。
3. **缺少长期视角**
  - 很多人只看当月收支，不看资产结构、负债压力和未来目标达成情况。
4. **手工维护成本高**
  - 资产估值、债务余额、投资持仓需要频繁更新，容易遗漏。
5. **财务目标执行难**
  - 很少有工具能把“买房首付”“应急金”“旅行基金”“提前还贷”等目标和实际资产联动起来。

### 1.2 产品机会

打造一个以**净资产为核心**的个人资产管理平台，统一管理：

- 资产
- 负债
- 收支
- 投资持仓
- 财务目标
- 提醒与报表

让用户随时知道：

- 我有多少资产？
- 负债还剩多少？
- 净资产增长了多少？
- 资产结构是否健康？
- 我的目标还差多少？

## 2. 产品目标



### 2.1 产品愿景

成为用户的“个人财务驾驶舱”，让个人资产管理从零散记录升级为可视化、可追踪、可预测的系统。

### 2.2 业务目标

1. 帮助用户在 3 分钟内完成资产概览建立。
2. 支持用户持续维护资产与负债，形成净资产趋势。
3. 支持用户建立财务目标，并跟踪达成进度。
4. 提高用户财务行为的可见性与执行力。



### 2.3 成功指标

- **注册完成率** ≥ 70%
- **首日完成资产录入率** ≥ 60%
- **7 日留存** ≥ 35%
- **月活跃用户资产更新率** ≥ 50%
- **目标创建率** ≥ 25%
- **提醒完成率** ≥ 40%
- **净资产图表查看率** ≥ 70%

### 3.1 画像一：理财小白

- **年龄**：22~35 岁
- **特点**：有工资收入，有银行卡、少量储蓄和信用卡

- **诉求**：看整体资产分布、收益变化、成本与市值
- **使用频率**：每日或每周多次



### 3.3 画像三：家庭财务管理者

- **年龄**：28~45 岁
- **特点**：有房贷、车贷、家庭开销、教育支出
- **诉求**：管理家庭资产负债，规划购房/换车/教育金
- **使用频率**：每周 1~3 次

## 7. 核心业务规则



### 7.1 净资产计算规则

```text
净资产 = 资产总额 - 负债总额
```



### 7.2 收支与资产关系

- 收入会增加现金/银行账户余额
- 支出会减少现金/银行账户余额
- 转账不计入收入或支出
- 借款入账计为负债增加，同时对应资产增加
- 还款分为：
  - **本金**：减少负债
  - **利息**：计为支出



### 7.3 投资资产估值规则

- 默认以**当前市值**计算资产价值
- 可查看：
  - 成本
  - 最新市值
  - 浮动盈亏
  - 收益率
- 支持手动更新价格
- 支持从导入文件批量更新



### 7.4 多币种规则

- 资产支持多币种
- 首页统一折算为基础币种
- 汇率使用：
  - 用户手动设置
  - 或系统每日更新汇率
- 报表支持按原币与基础币种双视图



### 7.5 数据删除规则

- 删除资产时需选择：
  - 仅删除资产
  - 同时删除关联记录
- 删除后进入回收站 30 天，可恢复

## 16. 风险与应对


| 风险      | 描述           | 应对策略             |
| ------- | ------------ | ---------------- |
| 用户录入成本高 | 手动维护容易流失     | 快速录入、模板、导入、复制上一笔 |
| 数据准确性不足 | 资产估值随时间变化    | 支持手动更新、行情刷新、变更记录 |
| 分类复杂    | 用户不愿设置复杂分类   | 预置默认分类，支持后期自定义   |
| 隐私担忧    | 财务数据敏感       | 加密、隐私模式、设备管理     |
| 需求膨胀    | 容易做成“全能理财平台” | 明确 MVP，只做资产管理主线  |
